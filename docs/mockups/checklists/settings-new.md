# The new Settings: keyboard and mouse look (A), controller look (B) (approved Nov 15, 2026)

Mockups: next-update/settings-A1-home-mouse.png, next-update/settings-A2-display-mouse.png, next-update/settings-B1-quick-controller.png, next-update/settings-B2-display-controller.png
Release: 1.14

The owner's choice: Settings shows layout A while you use a keyboard and mouse, and switches to layout B by itself
when it sees a controller being used (and back when the mouse or keyboard is used). Every page works in both.

## Switching between them
- [ ] A while the keyboard or mouse was used last, B while a controller was used last, switching live without losing your place
- [ ] the page and the setting you were on stay picked across the switch

## A: Home (settings-A1)
- [ ] left list: you (picture, name, Administrator · PC name), Search settings (Y), the 13 categories with the picked one marked
- [ ] the PC card: picture, name, Hearth OS version · mode · graphics card · processor, Rename and About this PC
- [ ] four quick tiles: Wi-Fi, Bluetooth, Updates, Hearth Link with their state
- [ ] Recommended settings: Night light, Light mode while you play, Do not disturb (switches with On/Off), Start in (Game Mode / Desktop Mode)
- [ ] Storage: each drive with its bar and used of total, Manage
- [ ] Changed lately: the last changes (what, from → to, who, when), each with Undo, and All changes
- [ ] button hints: A Select, B Back, Y Search, LB/RB categories, Close

## A: a page (settings-A2, System › Display)
- [ ] the page's path as its title (System › Display)
- [ ] the displays drawn as you have them (1, 2), with the main one's name, resolution, refresh, HDR and graphics card, Identify, Detect, Arrange
- [ ] sections with headings (Brightness & colour, Scale & layout, Related), each setting a row with its icon, name, line under it and its control (switch or choices)
- [ ] Related links to other pages (Game Mode's resolution and frame limit)
- [ ] X Keep these settings on a display change (and the old one back by itself if not kept)

## B: Quick (settings-B1)
- [ ] header "Settings" with the LB/RB tabs: Quick, System, Network, Devices, Gaming, Look, Accounts, Server
- [ ] big tiles: Light mode while you play (wide), Wi-Fi, Bluetooth, Brightness and Volume (with sliders), Start in (wide, Game Mode / Desktop Mode), Updates, Power, Night light, Do not disturb
- [ ] the focused tile lifted with the accent outline
- [ ] X Pin to Quick (pick which settings are on Quick)

## B: a page (settings-B2, System › Display)
- [ ] the category's pages listed on the left (Display, Sound, Power & battery, Storage, Keyboard, Date & time, About)
- [ ] big rows: sliders with their value, ‹ value › choices changed with left and right, switches, › for more
- [ ] the help panel for the focused setting: what it does, how to change it with the controller, and when it was last changed and by whom
- [ ] X Default (puts that one setting back, asking first)

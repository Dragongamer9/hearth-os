# Logitech G15 app (approved Nov 18, 2026: "heel yeah")

Mockups: g15/g15-1-overview.png, g15/g15-2-g-keys.png, g15/g15-3-keyboard-screen.png, g15/g15-4-lighting.png, g15/g15-5-screen-pages.png, g15/g15-6-make-your-own.png
Release: next

The app is hosts/hearth-ui/apps/g15 (hearth-g15-app); the service and the keyboard's screen are hearth-g15 (docs/G15.md).
Status (feature/logitech-g15): the service, the screen's pages and the test .deb first; the app's pages next.

## Every page (the frame)
- [ ] Title bar: the orange G icon, "Logitech G15", "· Hearth", minimize, maximize, close
- [ ] Sidebar: the keyboard picture, "G15", the green dot and "Plugged in" (or not)
- [ ] Sidebar pages: Overview, G-keys, Keyboard screen, Lighting, with their icons and the orange mark on the one open
- [ ] Sidebar foot: "Settings are saved as you change them. Also in Settings › Bluetooth & devices."
- [ ] Controller bar: A Select, B Back (and each page's own: X Test it, Y Record, X Show on the keyboard, X Delete, Y Add), LB Previous / next page
- [ ] Settings › Bluetooth & devices: one "Logitech G15" row that opens the app (Mantel's Settings and the Rust Settings app)

## 1. Overview (g15-1)
- [ ] "Your G15"
- [ ] The keyboard drawn: the flip-up screen showing the time, its five keys, M1 M2 M3 MR (the set in use lit), G1–G18 in 3 columns of 6, the main keys, the round button
- [ ] "Logitech G15 keyboard", "Plugged in · first model, 18 G-keys"
- [ ] Facts: Key set (M1 · Everyday), G-keys set up (11 of 18), Screen (the pages on), Keys light (High)
- [ ] Key sets: three cards (M1 · Everyday, M2 · Trainz, M3 · Empty) with how many keys and what they do, "In use" on the one in use, "Press M2 to use" on the others
- [ ] Switch key sets for each game (switch): "Starts M2 when Trains 2010 opens, back to M1 when it closes"
- [ ] Record a macro with MR (switch): "Press MR, type, then press the G-key to keep it on"

## 1. Made of blocks
- [ ] Big clock with the date under it
- [ ] Weather block: place, temperature, tonight's line
- [ ] Media block (Now playing): title, artist, position of length, previous, pause and next
- [ ] While you were away block: names only, no messages shown (your choice), "N more"
- [ ] Your downloads block: name, percent and a bar
- [ ] Battery block: this device's percent and time left, and the controller's battery
- [ ] Password block: your picture and name, password box with its arrow, "Fingerprint, or your password"
- [ ] The password block is always there and always on top, and can't be removed (its "always on top · can't be removed" tag)
- [ ] The line along the bottom saying what the blocks are
- [ ] Nothing on the lock screen can open an app, a file or a setting; only the password block unlocks

## 2. In the 1995 look
- [ ] "Hearth is locked" bar with the time
- [ ] The look's desktop icons (My Hearth, Bin), shown only
- [ ] "Welcome back to Hearth" window: picture, "Type your password to unlock this PC.", the password box, OK and Shut down...
- [ ] The same safety underneath: the password block drawn in that look
- [ ] Every ready-made desktop gets a matching lock screen

## 3. The editor
- [ ] "Your lock screen" side: Blocks · drag onto it (Clock, Date, Weather, Media, Notifications, Downloads, Battery, Calendar, Picture, Words, Friends online, Your AI's own...)
- [ ] Always there: Password and fingerprint, with its line (moved, sized and styled, never removed or covered)
- [ ] Match your desktop (Same as <your desktop>)
- [ ] Top: "Lock screen" with the layout's name, Undo, Try it (locks for real), Keep this
- [ ] The lock screen on a grid, the picked block outlined
- [ ] Or say it: a box that changes the lock screen from words (Describe it)
- [ ] The picked block's side: Shows (for Weather: Place, Tonight too), Look (Corners, See-through, Font), Privacy (Notifications names only, Media controls)
- [ ] The line: nothing on the lock screen can open an app, a file or a setting

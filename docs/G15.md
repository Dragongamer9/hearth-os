# Logitech G15 on Hearth OS

Hearth supports the Logitech G15 keyboard, first made for the owner's dad's keyboard: the first G15 (2006) with 18
G-keys, M1 / M2 / M3, MR, a light under the keys and a 160 x 43 screen that flips up. The G15 v2, G11 and G510 use the
same driver and work the same way (the v2 has 6 G-keys, the G11 no screen).

## What it does

- **G-keys:** each of the 18 keys does what you set, in three sets (M1, M2, M3: the set's light shows which is in use).
  A key can press a key or a combination (Ctrl+C), type text, play a recorded macro, open an app, or do one of
  Hearth's actions (the app menu, Quick Access, Settings, Files, Task Manager, a screenshot, lock, the power menu,
  volume, the next page on the keyboard's screen). A set can be picked by itself while a game runs.
- **Recording a macro (MR):** press MR (its light comes on and the screen says RECORDING), type on the G15, then press
  the G-key to keep it on. MR again, or an M-key, throws it away. Only the G15's own keys are read, and only while
  recording; what you type still reaches the app in front.
- **The keyboard's screen:** pages for the clock (with the weather your Weather widget last fetched), the PC (CPU and
  graphics card use and heat, memory), the song playing (any MPRIS player, through playerctl; the keys under the screen
  are previous / play-pause / next there) and Hearth's messages (a new one pops up for 5 seconds). The round key under
  the screen goes to the next page; the four others pick a page. Your own screens are made of text, values, bars,
  graphs, a clock, pictures, lines and boxes, each with a place and size (the app's editor), and one can show while a
  chosen game runs. Messages: recording, key set changed, a macro kept.
- **Lights:** the key light and the screen's light (off, low, high), remembered; the light button on the keyboard
  changes and remembers it too. Optional: lights off while the PC is locked or asleep, the key light low at night,
  the M-key lights.

## How it works

Linux's own driver, hid-lg-g15 (kernel 5.5 and later), already handles the keyboard: the G-keys come as KEY_MACRO1-18
on an input device named "Logitech Gaming Keyboard Gaming Keys", M1-M3 as KEY_MACRO_PRESET1-3, MR as
KEY_MACRO_RECORD_START, the keys under the screen as KEY_KBD_LCD_MENU1-5, and the lights are LEDs:
`/sys/class/leds/g15::kbd_backlight`, `g15::lcd_backlight` (both 0-2), `g15::macro_preset1-3`, `g15::macro_record`.
The screen is drawn through the G-key part's hidraw node: output report 3, 32 bytes of header, then 6 bands of 160 bytes
(each byte a column of 8 dots, bit 0 at the top), 992 bytes (as lcdproc's g15 driver and libg15 do it).

The first G15 shows up as three USB devices: 046d:c223 (the hub inside it), 046d:c221 (the ordinary keys) and
046d:c222 (the G-keys, the keys under the screen and the screen; hid-lg-g15 binds this one).

- `hearth-g15` (Rust, `hosts/hearth-ui/apps/g15`) is a small user service, `hearth-g15.service`, started by udev when
  the G-keys appear (`70-hearth-g15.rules`: `SYSTEMD_USER_WANTS`) and at sign-in when the keyboard is already plugged in
  (`/etc/xdg/autostart/hearth-g15.desktop`). Nothing wants it at start-up and nothing waits for it, so it can never
  stop Game Mode or the desktop from starting; without a G15 it's skipped, and it ends when the keyboard is unplugged.
  It sleeps in poll(): the screen is redrawn at most once a second (once a minute for the clock), only when it
  changed, and not while the screen's light is off or the PC is locked. Measured in CI at rest.
- No service runs as root. `70-hearth-g15.rules` gives the person at the PC (uaccess) the G-keys' input device, the
  screen's hidraw node and the G15's ordinary keys (read only while recording), and the video group the lights.
  Typing goes through a virtual keyboard (`/dev/uinput`, 70-hearth-uinput.rules, as hearth-pad does).
- Settings are in `~/.config/nimbus/g15.json`, written only through settings_file.rs (atomic, .bak, merged: red
  flag 9). Opening the app or plugging the keyboard in writes nothing; the keyboard's own keys (M1-M3, MR keeping a
  macro, the light button) save only what they change. The file's keys are listed in `src/config.rs`.
- `hearth-g15 status | present | light kbd|lcd N | frame PAGE OUT.png | make-fixture DIR`: the command line.
  `HEARTH_G15_FIXTURE=DIR` (made by `make-fixture`) is a pretend keyboard with pretend readings, for CI and pictures.

## A test build for Hearth OS 1.13 on Debian

The Actions workflow "Logitech G15 test .deb" (`g15-deb.yml`) builds `hearth-g15_0~test.<commit>_amd64.deb` in Debian
13. On Hearth OS on Debian, which is unlocked by default (`hearth-unlock --status`), opening the .deb installs it on
the system itself (the Install Package window, an administrator's password), and it stays across updates. Then unplug
the keyboard and plug it in again, or restart once. When Hearth OS comes with G15 support, remove the test package
(Settings › Apps, or `sudo apt remove hearth-g15`).

Every update since 1.5, newest first. All of it in one list: the release notes.

New in Hearth OS 1.12

A free update for everyone on 1.0 to 1.11: Settings › Updates.

Google Chrome, if you want it

Pick Hearth Browser or Google Chrome once after updating, in first-time setup, or any time in Settings. Chrome comes straight from Google and its signature is checked.

Minecraft: Java Edition, native

Horizon, the Rust remake of Minecraft: Java Edition, installs with one press in Hearth Games. No Java needed. Server mode can run a Horizon server too.

The AI team

Server mode shows a live map of your PC's AI: every device and AI asking it for something, what each engine is doing, and what happens while you play. Pause or restart it all at once.

Keep this running

Programs you mark are paused and moved out of memory instead of closed when memory runs out, then carry on right where they were.

A new Recovery USB

Hearth Recovery is now made from Hearth OS on Debian, with the same drivers and boot loader as your PC.

Fixes

Jellyfin installs again, and Task Manager's Memory page shows the programs using the most.

New in Hearth OS 1.11

A free update for everyone on 1.0 to 1.10: Settings › Updates.

Hearth Files

Games

Your home server

One AI address for all your devices, night maintenance, power history, and a warning before the main drive fills up.

In 1.8

This PC, the Briefcase, and a new Task Manager

Since 1.7

A brand-new Files, and Windows apps that just run

Hearth Files is rebuilt in the style of Windows 11's File Explorer and does everything a file manager should, Windows programs open with a double-click, and your games from GOG, Epic and Battle.net get Hearth's own store app.

  • Everything a file manager doesTabs you can drop files onto, drag and drop, select many by dragging a box, rename in place, undo and redo, and type to jump to a file.
  • Windows apps that just runDouble-click a .exe or .msi. GE-Proton is built in, so it works offline, and each app gets its own space and menu icon.
  • The Proton detectorPicks the right Proton for each game and app. If one closes right away, Hearth offers the next and remembers what works.
  • Hearth GamesHearth's own store app for GOG, Epic and Battle.net.

Server apps

One-click Minecraft, Valheim, Terraria and Palworld servers, and your own Vaultwarden, Immich and Navidrome, in Settings › Home server. Off until you turn them on.

Shares connect by themselves

A "Connect automatically" switch per share in Files. A device that's asleep is skipped, so signing in never waits.

AI video

Wan 2.2 in the home server's ComfyUI, sized to your graphics card, with a one-click download.

Since 1.4

Your gaming PC is also your home server

Share folders with every device in the house, reach them from anywhere through Tailscale, back everything up and run your own media server and AI, all from Settings › Home server, with a controller. The PC keeps playing games: big jobs wait while you play.

  • Shared foldersWindows PCs, phones, TVs and other Hearth devices open them like any network drive. Read only or read & write, with a 30-day recycle bin.
  • Anywhere, through TailscaleA private network for your own devices: open your files from work or school, send files with Taildrop and wake the PC from away.
  • Light mode while you playBackups, snapshots and clean-ups wait while Game Mode or a game runs, and the AI unloads from the graphics card. Sharing keeps working.
  • Off until you turn it onNothing is shared and no server runs until you choose it. The system drive is never shared or formatted.

Drives & undo

Drive health and temperatures, btrfs snapshots to bring back deleted or changed files, and new drives as more space, a mirror or a backup target, with a dry run first.

People

Accounts for the household that can only open shares, each with their own access and an optional folder with a size limit. Removing someone never deletes their files.

Alerts & power

A note when a drive is unhealthy or full, a backup fails or a mirror loses a drive. Sleeps when nobody needs it, never while you play, and wakes on a schedule or over the network.

Services

Jellyfin for movies, shows, music and photos, and files in a browser. Each is downloaded only when you ask, from its maker, with its checksum checked.

Family & home

A Family folder for everyone, and cameras on your network shown once one is found.

In Steam Game Mode too

Quick Access › Hearth Link shows the server in short, with Light mode and "Let paused jobs run now" a press away.

Updates that can always go back

Each update replaces the system in one piece and keeps the version before it startable. Three ways back, from the easiest:

1

The boot menu

The previous version stays in the boot menu. Pick it there, or go back from Settings.

2

Automatic fallback

If Hearth fails to start twice in a row, the previous version starts by itself and stays the default.

3

Hearth Recovery

Hold Volume Down while starting, or boot the Recovery USB: reinstall keeping your files, copy files off, send logs.

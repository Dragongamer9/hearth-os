Hearth OS

Pick up the controller. Your PC is a console now.

Hearth OS is a gaming OS you run with a controller. Game Mode puts every store's games in one library; Desktop Mode is a full Linux desktop, one button away. Free and open source.

0.6.59

What's new in 0.6.59

The biggest update Hearth has had. New desktops to choose from, a writable Peppermint, a new controller system, and mods you manage from the couch. Items marked Beta Experimental are built and checked automatically, but haven't been tried on enough real devices yet.

Peppermint is writable Beta Experimental

Install with apt or open a .deb file and it stays across restarts and comes back after an update. Lock it again whenever you like in Settings. Updates, going back, the automatic fallback and Recovery all keep working.

More desktops to choose from Beta Experimental

Hearth GNOME joins Hearth Classic and Hearth Plasma, each in Hearth's look with full controller control. Hearth COSMIC is coming on Anatase. If a desktop can't start, Hearth Classic opens instead.

Hearth Input Beta Experimental

Steam Input-style controller layouts: action sets, layers, long and double presses, chords, turbo, flick stick, and gyro on demand. Edit them with the controller, even over a running game.

Guide + X types anywhere Beta Experimental

Hearth's on-screen keyboard opens over any game or app in Game Mode, and in Hearth Classic and Hearth Plasma. The game keeps its focus and never sees the presses.

Hearth Mod Organizer Beta Experimental

Hearth's own Mod Organizer 2-compatible organizer, built in Rust. Profiles, load order, conflicts, FOMOD installers and Wabbajack lists, and your game's folder is never changed.

Mods in Game Mode Beta Experimental

Browse Nexus Mods, install, switch mods on and off and play a Wabbajack list from a game's page, all with the controller. Sign in to Nexus Mods and MEGA so downloads run by themselves.

One app of each kind Beta Experimental

Each desktop shows its own file manager, terminal and text editor, so you never see two of the same thing. Your files and settings stay when you switch.

Steam games no longer freeze Beta Experimental

On handhelds with Handheld Daemon, opening Quick Access over a Steam game could freeze it. Steam now keeps running while Quick Access is open.

Game Mode, built for the couch

Hearth starts straight into Game Mode. Steam, Epic, GOG, Xbox, Battle.net and your own games sit in one library, and every screen works with a D-pad, sticks and four face buttons.

Arrange Home your way

Home comes in a dozen layouts: a carousel, a bookshelf of spines, an orbit, a magazine page, widgets, a clock-first Focus screen. The library has its own set. Swipe through a few of them.

  • Quick Access over any game: performance, power limit, brightness, Wi-Fi, Bluetooth and the controller layout.
  • The Dragonfire look: a darker ember theme with performance rings and a Friends panel.
  • Downloads, store pages, achievements and ProtonDB ratings, without leaving the couch.

The covers in these layouts are Hearth's own placeholder art for sample games.

Desktop Mode, and the desktop is your choice

Press one button and you're on a full Linux desktop with Hearth's launcher, Quick Access, Hearth Link and Hearth Storage, still driven by the controller. Pick the desktop in Settings or at sign-in; switching keeps your files and settings.

Hearth Classic The default

Hearth's own desktop (labwc with the Mantel shell): light, quick on a handheld, and the one every other desktop falls back to. Press the Guide button for the Hearth menu.

Hearth Plasma Since 0.6.58

KDE Plasma 6 in Hearth's colours, with Hearth's launcher, Quick Access, Hearth Link, Hearth Storage and Game Mode as widgets, and Hearth Files built from Dolphin. A first version: it doesn't match Hearth Classic part for part yet.

No screenshot yet.
Hearth GNOME is still being finished.

Hearth GNOME Coming, Beta Experimental

GNOME in Hearth's colours with a floating bottom bar, Hearth's launcher, Quick Access, Hearth Link and Hearth Storage built in, and full controller control. GNOME's own Files, Console and Text Editor come along in Hearth's look.

Hearth COSMIC Coming, Beta Experimental Anatase only

System76's COSMIC desktop in Hearth's look, with Hearth's launcher, Quick Access, the Hearth menu and the on-screen keyboard. It's planned for Anatase, where Fedora packages COSMIC; Debian doesn't have it yet, so Peppermint will show it as not available.

Not available on either edition yet.

Hearth Deepin Not available yet

Hearth only ships a desktop it can get properly from the edition's own distribution. Fedora and Debian don't offer the Deepin desktop right now, so it's listed but greyed out. It can come later if they bring it back.

Hearth Input

A controller that works everywhere, with layouts as deep as Steam Input's.

  • Guide + X opens the on-screen keyboard over any game or app. B or Guide + X closes it.
  • Layouts with action sets, layers, long, double and release presses, chords, turbo and toggles; sticks as a D-pad, a scroll wheel or a flick stick.
  • Gyro always on, on a button with a ratchet, or while you touch the right stick.
  • A global layout for games without their own, and your layouts from your other Hearth devices.

Built and checked in CI; still being tried on more controllers.

Everything else Hearth does

Your devices, your mods, your stores, your friends on the couch.

Hearth Link

Pair your Hearth devices: copy games between them, Continue on this device, update every device at once with a single download, and share a device's local AI with the others.

Hearth Storage

A spare Hearth PC becomes a home server: shared folders, a game archive with fast copy-back, save and screenshot backups, media streaming, wake over the network, and an optional Windows share.

Mods Beta Experimental

Hearth Mod Organizer keeps Mod Organizer 2's layout and files, so existing setups import in place. Wabbajack lists install with downloads from Nexus Mods and MEGA handled by themselves, and a guided flow for the files that need a click. All of it is in Game Mode on each game's page.

Not yet tried with every real modlist; Windows Mod Organizer 2 stays available per list as the fallback.

Hearth Theater New, Beta Experimental

Your own wall of video sites, opened full screen from Game Mode's menu and driven with the controller, with its own pointer for the sites that need one.

Every store in one place

Steam, Epic, GOG, Xbox Cloud and your own games, plus Battle.net set up with one press and Blizzard games in the library, and Xodus Nexus preinstalled for your Xbox PC games.

Couch co-op and multi-seat

Several players on one PC, each with their own controller and their own games. Player 1's GOG games on every seat, shared Epic installs, and Steam Family games per seat with "In use by…".

Hearth Benchmark

Processor, memory, storage, graphics, sustained load and heat, battery and network, with a history and a compare between your devices.

The Hearth apps

Hearth Files, Terminal, Text, Paint, Photos, Capture, Disks with a bootable USB maker, a controller-friendly browser, Friends with chat, and System Info, each in Hearth's look.

The previous version stays

Each update replaces the system in one piece and keeps the version before it. Go back from Settings or the boot menu.

Automatic fallback

If Hearth fails to start twice in a row, the previous version starts by itself and stays the default.

Hearth Recovery

Hold Volume Down while starting, or boot the Recovery USB: reinstall keeping your files, copy files off, send logs.

Set up with a controller

From the first screen, no keyboard needed. Connect a controller, join Wi-Fi, and install or just try Game Mode from the USB stick.

Get Hearth OS

Write the ISO to a USB stick of 16 GB or more (with Hearth Disks, Ventoy, Rufus or balenaEtcher), start your PC or handheld from it, and follow the screens. Installing needs a drive of 64 GB or more.

Offline USB

Everything on the stick, so it installs without internet. Also lets you try Game Mode first.

Support Hearth OS

Questions

What hardware does it need?

Steam Deck, ROG Ally, Legion Go and most x86-64 desktops and laptops with AMD, Intel or Nvidia (GTX 16 / RTX 20 and newer) graphics. For installing, a USB stick of 16 GB or more and a drive of 64 GB or more.

Can I go back to the last version?

Yes. Updates keep the previous system in the boot menu; pick it, or use Settings › System › Updates. A version that fails to start twice in a row goes back by itself, and holding Volume Down while it starts opens Hearth Recovery. If nothing starts, the Recovery USB can start the previous version.

Which edition should I pick?

Anatase if you want a system that can't be changed by accident. Peppermint if you want to install Debian packages with apt. Both get the same Hearth, the same updates and the same Recovery, and you can switch in Settings.

Does it work with anti-cheat games?

Nothing is injected into games; the overlay is an ordinary window. Couch co-op doesn't support anti-cheat games.

Is it really free?

Yes. Hearth OS is free and open source under the GPL-3.0. Games you buy come from the stores as usual.

Something broke. How do I report it?

Send logs from Settings › System › Help & logs or with hearth-send-logs, and tell us what happened.

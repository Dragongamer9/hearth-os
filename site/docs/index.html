What Hearth OS is

Hearth OS is a controller-first gaming system for handhelds and PCs. It starts in Game Mode, a console-style screen with Steam, Epic, GOG, Xbox and your other games in one library, and has a full desktop one button away (Desktop Mode: KDE Plasma with Hearth's own apps). It's built on Fedora.

It's image-based: the whole system is one tested image that updates in one piece, in the background. An update can't half-install, and the version you had before stays on the drive so you can go back to it.

Hearth OS is in beta. It works for everyday play, but expect rough edges. When something breaks, send a log and it gets looked at.

Editions

Hearth looks and works the same on every edition. What changes is the Linux underneath it.

EditionBuilt onStatusGood for
FedoraFedora (Anatase)RecommendedEveryone. The main edition, the one that gets updates. Locked by default and updated in one piece; the file system can be unlocked in Settings.
DebianDebian 13ArchivedMerged into the Fedora edition. Installs keep working; switch to Fedora to keep getting updates.

Both have the automatic fallback (an update that doesn't start goes back by itself) and Hearth Recovery. You can switch edition later without a USB stick. Your games and saves come along.

Fedora is the main version of Hearth OS. The Debian edition has been merged into it and archived, as Ubuntu and CachyOS were before. Already on Debian? Switch to Fedora: your home folder stays as it is, and Debian stays in the boot menu so you can go back.

About your edition

Pick your edition above to see what's particular about it.

Fedora: Hearth OS on Fedora (Anatase), made into an image (bootc). It's the main edition: every change is tested on it first, and it's the one that gets updates. Desktop Mode is KDE Plasma with Hearth's apps in its menu.

  • Apps: Flatpak, from Flathub, in the Bazaar app store (Desktop Mode).
  • The system is locked by default and updates in one piece. To install packages with dnf anyway: Settings › Updates & Recovery › Unlock the file system. What you add with dnf comes back by itself after an update.
  • Steam: built in.

Debian: Hearth OS on Debian 13 "trixie". Archived Merged into the Fedora edition: Fedora is the main version now. A Debian install keeps working, and Switch edition moves it to Fedora with your home folder as it is.

  • Apps: Flatpak, from Flathub, in the Bazaar app store (Desktop Mode).
  • Steam: built in, from Debian's packages.

What you need

  • A 64-bit PC or handheld (x86-64) with AMD, Intel or Nvidia graphics (Nvidia GTX 16 / RTX 20 or newer).
  • For installing: a USB stick of 16 GB or more, and a drive of 64 GB or more.

Tested on the ASUS ROG Ally and Xbox Ally, and desktop PCs with AMD and Nvidia graphics.

Docs · for Hearth OS 1.6

Steam Game Mode

Steam's own Game Mode is now Hearth's first priority, with Hearth built into it. Hearth's Game Mode stays as the fallback and as an option.

Coming in the next update. Hearth OS 0.6.61 already has Steam Game Mode, Hearth's look over it, Hearth's home screen and pages, your Hearth games in Steam's library and Start in Steam Game Mode. Everything marked Next update on this page isn't released yet. All of it is Experimental and still needs testing on real devices.

What changes

Steam's own Game Mode is now Hearth's first priority. That's Valve's gamepad screens, full screen, the way SteamOS and a Steam Deck run them. Hearth is built right into it through Decky Loader and the Hearth Decky plugin.

You keep everything that's Steam's: the library, game pages, store, downloads, friends and chat, the overlay, Quick Access and the on-screen keyboard. Hearth adds its own stores, pages and tools on top. It doesn't replace Steam's.

Next update Hearth OS is now Debian + Mantel (Desktop Mode) + Steam Game Mode: the device starts in Steam Game Mode and every Game Mode button opens it. If Steam can't start (not installed, safe graphics, Steam closing right away or failing twice), Mantel opens and says why, with a Try Steam Game Mode again button. Hearth's own Game Mode is archived (first-time setup still runs in Hearth's app once), and multi-seat and Couch Co-op are hidden for now.

Hearth in Steam's main menu

Next update Press the Steam (or Xbox) button. Below Steam's own entries, in Hearth's look:

  • Now playing, while a game runs: opens Hearth's section for that game.
  • Hearth: Hearth Home, Hearth Store, Hearth Library, Theater, Hearth Mods, Storage, Downloads, Hearth Friends, Hearth Link.
  • Hearth power, next to Steam's Power: Desktop Mode.

Hearth tabs in Quick Access

Next update Press the … button. Hearth's tabs sit next to Steam's:

TabWhat's in it
HearthThis game, Quick Resume, game streaming, Hearth tools (keyboard, screenshot, record), Desktop Mode, Hearth OS updates

Hearth ControllerWhat Hearth Input is doing, the running game's Hearth Input layout, and Edit layouts in Hearth

The game you're playing

Next update While a game runs, Hearth shows a section for it in Steam's main menu, in Quick Access and on its own page:

  • its Hearth Input layout;
  • its Proton version, for games Hearth starts with Proton (Steam's games keep Steam's own setting);
  • its mods in Hearth Mods, with a button to open Hearth Mods;
  • its ProtonDB rating and achievements.

Store, Mods, Storage and Recomps

Hearth's home screen, Store, Library, Downloads and Storage pages are already in Steam's Game Mode in 0.6.61. Next update These pages now change things too, not only show them:

  • Store: open a game's details. Buy opens the store's own page in Steam's browser (Hearth never sees payment details or passwords). Install Epic and GOG games with progress, cancel, and Play.
  • Mods: turn a game's mods on and off, uninstall them, or install ones you downloaded.
  • Storage: your drives, games by size, Move to another drive, uninstall, clean up, and pick a drive for new games.
  • Recomps: install a port with progress, play it, uninstall it (saves are backed up).

Steam's own games are installed, moved and uninstalled by Steam, not by Hearth. Their buttons open Steam's page or Steam's storage settings.

Quick Resume, streaming, Friends and Hearth Link

Next update

  • Quick Resume: Put aside pauses the game Steam is running, right where it is, and takes you to Steam's library. It carries on when you go back to it. Steam runs one game at a time, so it's one game here.
  • Game streaming: turn Sunshine on or off, see the Moonlight devices paired, and Pair a device with a number pad for Moonlight's 4-digit PIN.
  • Hearth Friends: who's online and what they're playing. Chats and requests open in Hearth's Friends.
  • Hearth Link: your paired devices, Sync now, and Hearth Storage devices with Wake it.

Couch co-op and multi-seat

Next update Couch co-op: pick a split-screen game in Quick Access › Hearth Players, choose how many play and how the screen is shared, then Play split-screen or Add to Steam library. Either way it becomes one Steam shortcut, so Steam shows it running and Exit game closes everyone's copy.

Multi-seat: with multi-seat set up, player 1 can play in Steam's Game Mode while the other players keep their own Hearth Game Mode, each on their own account, screen and controllers. Multi-seat and couch co-op are hidden for now.

Your Hearth games in Steam

Quick Access › Hearth › Sync to Steam library adds your Epic, GOG, Battle.net, Xbox PC, Beacon, emulator and added games to Steam's library, with Hearth's cover art. They play through Hearth, so Steam shows them running, gives them the overlay and counts the play time. Remove Hearth's shortcuts takes them out again.

How to try it

  1. In Desktop Mode, open Settings › Steam Game Mode.
  2. Optional, once: Decky Loader and the Hearth plugin › Install. It asks for your password. Without it you still get Steam's Game Mode, just without Hearth inside it.
  3. Switch to Steam Game Mode (also in the power menu). If Steam isn't signed in yet, sign in on Steam's own screen.

About Decky: Decky Loader runs as root while Steam Game Mode runs, and it turns on Steam's local remote debugging. Only install Decky plugins you trust. Remove in Settings takes it all away again.

Hearth's old Game Mode

Hearth's own full-screen Game Mode is archived. It still runs Hearth OS's first-time setup once after installing, and it's the very last fallback; you won't see it anywhere else. Everything you set there is now in Desktop Mode's Settings or in an app of its own (Mods, Saves, Controller Lab, Friends, Theater, Hearth Link...). Developers can bring it back with HEARTH_LEGACY_GAME_MODE=1.

If Steam's Game Mode won't start

All of these work with just a controller:

  • Desktop Mode opens by itself and says why, with Try Steam Game Mode again.
  • Hold B or Guide while the device starts: it starts in Desktop Mode that time.
  • Hearth Recovery (hold Volume Down while it starts).

Switching never touches the boot menu or the login screen.

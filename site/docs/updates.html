Updates and editions

Hearth OS updates itself in one piece. Here is how that works, how to go back, and how to switch edition.

How updates work

  • Hearth checks for updates when it starts and every 6 hours (Settings › Updates › Check automatically).
  • An update downloads in the background while you play. It's used the next time you restart.
  • The whole system is replaced in one piece, so an update can't half-install. The version before it stays on the drive.
  • To update now: Settings › Updates › Check for updates, then restart when it says it's ready.

From a terminal in Desktop Mode, the same update:

pkexec /usr/libexec/nimbus/hearth-admin update

Going back to the last version

If a new version has a problem, go back to the one before it.

From the boot menu

Restart, and in the boot menu pick the second Hearth OS entry (the older version). On a handheld, the boot menu can be moved with the D-pad or volume buttons.

From a terminal

This makes the version before the default, from the next restart on:

sudo bootc rollback

Then restart. The next update moves you forward again.

Switching edition

Move between Anatase and Peppermint without a USB stick: Settings › Updates › Switch edition. On Ubuntu or CachyOS (archived for now) the same button moves you to Anatase or Peppermint.

  • Kept: your account, your games, saves and store libraries (Steam, Epic, GOG...).
  • Set aside: the rest of your home folder goes into a folder called .old-hearth- plus the date, for 30 days, so you can copy back anything you need. After 30 days it's deleted.
  • The new edition downloads in the background (about 3 GB), then starts at the next restart. Before anything starts you see exactly what's kept.

Installed from 0.3.0 or earlier: switching edition (and updating) fails with "podman executable not found in PATH". See the fix.

Switching from a terminal

The same switch as the Settings button. Change peppermint to anatase for the other edition:

pkexec /usr/libexec/nimbus/hearth-admin move-to-new-os --edition peppermint

When it says Done. Restart to start the new Hearth OS., restart.

Using Hearth

Game Mode, the desktop, the controller and keyboard, the power button, and sending logs.

Game Mode and Desktop Mode

Game Mode is the console-style screen Hearth starts in. Desktop Mode (Mantel) is a full desktop with windows, a file manager and a terminal.

  • To the desktop: Power › Switch to desktop in Game Mode.
  • Back to Game Mode: the Game Mode button at the bottom right of the desktop.
  • Settings › Sign-in › Start in picks which one you see after signing in.

The on-screen keyboard

Laid out like SteamOS's, at the bottom of the screen. With a controller:

ButtonDoes
AType the selected key
YDelete
XSpace
LBShift (twice for caps lock)

BClose

The ← and → keys move the text cursor. A USB or Bluetooth keyboard works too.

The power button

Settings › Power › Power button sets what a quick Press and a Hold do (sleep, the power menu, turn off). Holding the button for several seconds always turns the device off.

Display and performance

  • Settings › Display › Drawing engine: on Nvidia graphics Hearth uses Chromium to draw Game Mode, which is much smoother there. It's chosen automatically.
  • Settings › Power: power mode and the power limit (TDP) on handhelds.

Profiles and stores

  • Each Hearth profile can sign in to its own Steam account. With more than one profile, each sees its own Steam games.
  • Stores are signed in to from Settings › Game stores. Beacon (the Battle for Middle-earth launcher) is built in.

Hearth's own apps

On Hearth OS and on Windows (Ember), from Desktop Mode's app menu or the Start menu:

  • Hearth Browser: real Firefox with Hearth's look. Google sign-in, streaming video and uBlock Origin work. In Game Mode it opens full screen with bigger buttons and an on-screen keyboard (it opens by itself when you pick the address bar; or the Keyboard button, or Ctrl+Alt+K).
  • Terminal: tabs, split view (Ctrl+Shift+D), find (Ctrl+Shift+F), themes, and a quick-keys bar and on-screen keyboard for controllers. Your shell on Linux; PowerShell, Command Prompt or WSL on Windows.
  • Disks: your drives and their health, formatting USB drives and SD cards, partitions, and Use for games (a drive or SD card as a Steam library in one step). It won't touch the drive the system runs from.
  • hearthfetch: type it in the Terminal for a summary of your system.

Desktop Mode's app drawer has a Games tab with your installed games; on Windows it also has a Windows tab with the built-in programs.

Installing Claude

Claude, Anthropic's AI assistant, can be installed on every edition. It goes in your home folder, so it doesn't change the system and stays through Hearth OS updates. Sign in with your Claude account in the browser when it asks.

  • Claude Desktop (the app: chat, Cowork and Claude Code sessions): Get Claude in Desktop Mode's app menu, or Hearth Settings › Claude, or in Game Mode Settings › System › Claude. Hearth downloads Anthropic's own package from downloads.claude.ai, checks it against Anthropic's signing key, installs it and opens it.
  • Updates: Anthropic's Linux app doesn't update itself, so Hearth checks for a newer one every day and installs it (if Claude is open, the next time it's closed). Check for an update on the same page does it now.
  • Claude Code (Claude in the Terminal, for coding): Get Claude Code on the same page runs Anthropic's installer for you. Then type claude in the Terminal. It keeps itself up to date.

From the Terminal instead:

hearth-claude install
hearth-claude install-code

hearth-claude status, update and remove do the rest (remove-code for Claude Code). Removing keeps your chats (they're in your Claude account) and settings.

Anthropic supports Claude Desktop for Linux (in beta) on Debian and Ubuntu. On Anatase, Hearth runs Anthropic's Debian build from your home folder: it should work, but Anthropic doesn't support it there yet. Claude Code is supported everywhere.

On Peppermint you can also install claude-desktop with apt from Anthropic's repository, following Anthropic's instructions. Then apt keeps it up to date and Hearth leaves it alone.

Sending logs

When something goes wrong, Settings › System › Send logs to the developer. You get a short code (like ABCD-EFGH-JK): share it when you report the problem. Logs are kept 14 days, personal details are taken out before they're sent, and only someone with the code can read them.

Using Hearth

Game Mode, the desktop, the controller and keyboard, the power button, and sending logs.

Game Mode and Desktop Mode

Game Mode is the console-style screen Hearth starts in. Desktop Mode (Mantel) is a full desktop with windows, a file manager and a terminal.

  • To the desktop: Power › Switch to desktop in Game Mode.
  • Back to Game Mode: the Game Mode button at the bottom right of the desktop.
  • Settings › You › Sign-in › Start in picks which one you see after signing in.

The dock and Settings

Menu (☰) opens the dock along the bottom: Home, Library, Store, Friends, Downloads, Hearth Link, then Search, Settings, Power and your profile. Left and right move along it; the item you're on shows a card above it (who's online, the download queue with Pause all, your devices...), and up goes into the card's buttons. While you browse, a small copy sits at the bottom edge for the mouse. Over a game it shows the game instead: Resume, Quick Access, Invite a friend, Exit game, a screenshot, recording and performance.

Prefer the old menu? Settings › You › Appearance › Menu style › Side menu (classic).

Settings has six groups along the top (You, Connections, Display & sound, Controls & power, Games, System), each with a summary on the left and its pages on the right. Inside a group, LB and RB move between its pages and B goes back. Search (Y, or the search button in Settings) finds settings too: type "refresh" to get to the refresh rate.

The on-screen keyboard

Laid out like SteamOS's, at the bottom of the screen. With a controller:

The ← and → keys move the text cursor. A USB or Bluetooth keyboard works too.

The power button

Settings › Controls & power › Power & sleep › Power button sets what a quick Press and a Hold do (sleep, the power menu, turn off). Holding the button for several seconds always turns the device off.

Display and performance

  • Settings › Display & sound › Display › Renderer: on Nvidia graphics Hearth uses Electron (Chromium) to draw Game Mode, which is much smoother there. It's chosen automatically.
  • Settings › Controls & power › Power & sleep: power mode and the power limit (TDP) on handhelds.

Profiles and stores

  • Each Hearth profile can sign in to its own Steam account. With more than one profile, each sees its own Steam games.
  • Stores are signed in to from Settings › Games › Game stores & accounts. Beacon (the Battle for Middle-earth launcher) is built in.

Hearth's own apps

On Hearth OS and on Windows (Ember), from Desktop Mode's app menu or the Start menu:

  • Hearth Browser: real Firefox with Hearth's look. Google sign-in, streaming video and uBlock Origin work. In Game Mode it opens full screen with bigger buttons and an on-screen keyboard (it opens by itself when you pick the address bar; or the Keyboard button, or Ctrl+Alt+K).
  • Terminal: tabs, split view (Ctrl+Shift+D), find (Ctrl+Shift+F), themes, and a quick-keys bar and on-screen keyboard for controllers. Your shell on Linux; PowerShell, Command Prompt or WSL on Windows.
  • Disks: your drives and their health, formatting USB drives and SD cards, partitions, and Use for games (a drive or SD card as a Steam library in one step). It won't touch the drive the system runs from.
  • hearthfetch: type it in the Terminal for a summary of your system.

System tools (Hearth OS, Beta Experimental), in the app menu too:

  • Disk Usage: what's filling a drive, as a ring chart and a list. Click into folders, open them in Hearth Files, move things to the Trash, and quick finds for big files, old downloads and caches.
  • System Info: your device, processor, graphics and driver, memory, drives and their health, battery health, screens and Hearth's version. Copy as text for a forum post or a bug report.
  • Logs: the system's and Hearth's logs, easy to read, with filters (this start, errors only, one app, the last hour) and search. Send to the developer sends them the same way as Settings does.
  • Network Tools: a speed test, what's connected and which apps use the network, Wi-Fi signal and channel, ping, traceroute and DNS lookup.
  • Passwords & Keys: the passwords apps saved in your keyring and your saved Wi-Fi passwords. Showing a password asks for yours first. Nothing leaves the device.
  • Printers & Scanner: the print queue (pause, cancel), adding a printer, and scanning to PDF (several pages) or PNG.
  • Welcome & Tips: a short tour the first time, and this help, searchable, from the app menu.

Desktop Mode's app drawer has a Games tab with your installed games; on Windows it also has a Windows tab with the built-in programs.

Installing Claude

Claude, Anthropic's AI assistant, can be installed on every edition. It goes in your home folder, so it doesn't change the system and stays through Hearth OS updates. Sign in with your Claude account in the browser when it asks.

  • Claude Desktop (the app: chat, Cowork and Claude Code sessions): Get Claude in Desktop Mode's app menu, or Hearth Settings › Claude, or in Game Mode Settings › System › Device › Claude. Hearth downloads Anthropic's own package from downloads.claude.ai, checks it against Anthropic's signing key, installs it and opens it.
  • Updates: Anthropic's Linux app doesn't update itself, so Hearth checks for a newer one every day and installs it (if Claude is open, the next time it's closed). Check for an update on the same page does it now.
  • Claude Code (Claude in the Terminal, for coding): Get Claude Code on the same page runs Anthropic's installer for you. Then type claude in the Terminal. It keeps itself up to date.

From the Terminal instead:

hearth-claude install
hearth-claude install-code

hearth-claude status, update and remove do the rest (remove-code for Claude Code). Removing keeps your chats (they're in your Claude account) and settings.

Anthropic supports Claude Desktop for Linux (in beta) on Debian and Ubuntu. On Anatase, Hearth runs Anthropic's Debian build from your home folder: it should work, but Anthropic doesn't support it there yet. Claude Code is supported everywhere.

On Peppermint you can also install claude-desktop with apt from Anthropic's repository, following Anthropic's instructions. Then apt keeps it up to date and Hearth leaves it alone.

Sending logs

When something goes wrong, Settings › System › Help & logs › Send logs to the developer. You get a short code (like ABCD-EFGH-JK): share it when you report the problem. Logs are kept 14 days, personal details are taken out before they're sent, and only someone with the code can read them.

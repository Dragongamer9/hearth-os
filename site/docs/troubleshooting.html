Troubleshooting

Fixes for known problems, how to get unstuck, and how to tell us when nothing here helps.

Each fix says which version it's for. Most known problems are fixed by updating: Settings › Updates › Check for updates. Under every command, tell us whether it worked: that's how we know which fixes need work.

First: send a log

Settings › System › Send logs to the developer, then share the code. The log shows what Hearth saw at the moment it went wrong, so send it right after the problem happens.

Getting to a terminal

  • Desktop Mode: open Terminal from the app menu.
  • When the screen is stuck: with a USB keyboard, press Ctrl + Alt + F3 and sign in with your user name and password. Ctrl + Alt + F1 (or F2) goes back.

Switching edition or updating fails: "podman executable not found"

Peppermint, Ubuntu, CachyOS · 0.3.0 and earlier Fixed in 0.3.1

Those images were missing a tool (podman) that switching and updating need, and updating to the fix needs it too. This runs the switch with podman unpacked into a temporary folder (nothing is installed; it's gone after the restart). Change ubuntu to the edition you want:

curl -sL raw.githubusercontent.com/Dragongamer9/hearth-os/main/tools/switch-edition.sh | sh -s ubuntu

When it says Done. Restart to start the new Hearth OS., restart. A "could not find netavark" line along the way is only a warning.

Stuck on a black screen, or Hearth doesn't respond

  1. Wait half a minute. Starting a game or switching modes can take a moment.
  2. Hold the power button for about 10 seconds to turn the device off, then turn it on again.
  3. Still stuck after starting? Pick the older Hearth OS entry in the boot menu (going back), then send a log from there.

The power button turns the device off instead of sleeping

0.2.10 and earlier Fixed in 0.3.0 Update. After updating, Settings › Power › Power button is followed.

Brightness doesn't change ("get write permission")

Peppermint, Ubuntu · 0.3.0 and earlier Fixed in 0.3.1 Update and restart. If you can't update yet, this gives your account permission (then restart):

sudo usermod -aG video $USER

Lines of text when turning on and off

Anatase · 0.2.10 and earlier Fixed in 0.3.0 Update, then restart once. Or, right away (then restart):

sudo rpm-ostree kargs --append-if-missing=quiet --append-if-missing=splash --append-if-missing=loglevel=3

Game Mode sounds fade out

Fixed in 0.3.1 Update. Until then, restarting Hearth brings the sounds back for a while.

Stuck in Steam's Game Mode

0.2.8 and 0.2.9 Removed in 0.2.10 Steam's own Game Mode was an option in 0.2.8 and 0.2.9. If a device is stuck in it: with a USB keyboard press Ctrl + Alt + F3, sign in, and run (then restart):

echo hearth > ~/.config/nimbus/game-mode && sudo reboot

Game Mode feels slow on Nvidia

Check Settings › Display › Drawing engine is Chromium (the default on Nvidia since 0.2.6), and update.

Steam games are missing from the library

Make sure Steam is signed in. With more than one Hearth profile, each profile shows the games of the Steam account signed in on it: sign in to Steam on that profile.

Installing fails

  • Try the offline USB for your edition instead of the small installer (no download to go wrong).
  • If the install says it failed but the computer later starts Hearth OS anyway, it may have finished: check Settings › Updates and update.
  • From the live USB, Settings › System › Send logs to the developer includes the installer's log.

Still stuck? Tell us

Describe what happened. It goes straight to the developer, like a log, and you get a code to quote if you follow up. Don't include passwords.

Requests

Ideas for Hearth OS, changes you'd like, and editions on other Linux: ask here.

What you can ask for

  • A new feature, or a change to one that's there: something in Game Mode, the desktop, Settings, the stores.
  • A new edition: Hearth OS on another Linux (for example another family than Fedora, Debian/Ubuntu or Arch).
  • Device support: a handheld, controller or PC part that doesn't work well yet.
  • Anything else: games, launchers, the website, these docs.

Something broken? That's a problem report instead, so it gets fixed first.

What happens to a request

  1. It reaches the developer, straight away, with a code you can quote later.
  2. Requests are read and grouped: the same idea from several people counts for more.
  3. What's planned goes under Coming next, and the release notes say when it arrives.
